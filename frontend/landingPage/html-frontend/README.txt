# ResearchIQ — HTML/CSS/JavaScript Version

This folder is the converted frontend of the supplied React project.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage for saved funding opportunities

## Run
Open `index.html` in a browser.

For best results, use VS Code + Live Server:
1. Open this folder in VS Code.
2. Right-click `index.html`.
3. Select "Open with Live Server".

## Pages
- `index.html` — ResearchIQ landing page
- `funding.html` — Discover Funding Opportunities dashboard

## Working features
- Landing page navigation
- Explore Intelligence → Funding Dashboard
- Back to ResearchIQ
- Funding search
- Popular search chips
- Filters
- Clear filters
- Sort by AI match
- Save / unsave funding opportunities with ♡ / ♥
- Saved Opportunities sidebar
- Saved state persists in browser localStorage
- Notepad-style View Document panel
- Close document
- Sidebar section selection
- Responsive layout
